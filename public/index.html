Core safety rule

NFC can request payment. NFC cannot approve payment. The wallet owner must review and confirm before any Travel Pocket debit.

Travel payment flow

NFC or QR request -> TravelPaymentIntent -> Travel Pocket review -> Owner confirmation -> test-mode debit only after approval
